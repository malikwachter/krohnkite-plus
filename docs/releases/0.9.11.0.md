# Kröhnkite 0.9.11.0

Kröhnkite 0.9.11.0 brings an interactive layout chooser, a new overcapacity
policy, multi-window docks and a dwindle mode for the Binary Tree layout, with
61 commits since 0.9.10.0.

## Highlights

- **Interactive layout chooser** — the new `LayoutChooser` action and
  `LayoutChooserSC` shortcut open a clickable palette of the enabled layouts on
  the active screen. A click applies a layout immediately; `FocusLeft/Right/Up/Down`
  and `DWMLeft/DWMRight` move the selection and apply it too, the card border
  highlights on hover, and the pointer moves to the screen centre. The shortcut
  toggles the chooser on its screen and opens it on another one.

- **Overcapacity handling** — windows above a surface's capacity can now be
  minimized instead of floated. In the new default Minimize mode the selected
  window is hidden and restored in LIFO order when a slot frees up; Float keeps
  the old behaviour. The eviction policy (last focused or oldest, default
  oldest) applies to both modes. "Allow shortcut moves to a full surface" lets
  a move shortcut land on a full surface and evict another window instead of
  rejecting the move. The new `ShowCurrentCapacity` action reports the
  effective capacity and is bound as the register action of
  `RaiseSurfaceCapacity`.

- **Docks with several windows per side** — left/right docks stack vertically
  and top/bottom docks horizontally. Drag into a quarter zone to insert, into
  the middle zone to swap, and reorder with shortcuts across edges. Sides are
  weighted and the dock area cap is raised to 70%.

- **Dwindle Binary Tree** — a new window splits the focused tile along its
  longer edge; unlocked splits follow the longer edge on every arrange while
  manual flips stay locked. Directional moves enter the adjacent tile, trade
  sides with a lone sibling and create an outer tile at the edge. Windows can be
  dragged onto a tile half or the outer edge with live rearrangement, and
  `SwapUp`/`SwapDown` exchange contents without changing tiles. (#30, #31)

- **Pointer options** — "Move pointer to focused window center on resize" (off
  by default) moves the pointer when the active window changes size, coalesced
  after the layout settles and suppressed during and shortly after a mouse move
  or resize. "Only on Krohnkite shortcuts" (off by default) restricts pointer
  following to focus changes made through Krohnkite shortcuts.

- **Settings** — every layout has an enable checkbox and the rotation order
  starts at 1. Disabled layouts are skipped and greyed out. The configuration
  dialog now floats in System Settings, KDE system windows are always ignored,
  Spread spacing is disabled with its layout, and the Meta focus/move options
  are grouped under Normal.

## Tooling

- Reload without logging out: `go-task reload` rebuilds, installs and reloads
  through KWin's scripting interface, and `go-task reload-file <path>` reloads
  an already built directory or `.kwinscript`. Archives are validated before
  KWin is touched, reloads are serialised, and the last working bundle is kept
  for recovery. (#74)

- The autoinstall daemon reloads Kröhnkite after a successful install, so a
  build dropped into its watch folder takes effect immediately.

## Translations

- Updated Russian and Chinese translations, including the new overcapacity and
  pointer settings.

## Compatibility

- KWin 6 only.
- After upgrading, log out and back in (or restart the compositor) so KWin
  loads the new package. Reopen `System Settings → Window Management → KWin
  Scripts` to see the new settings page.
- Existing configurations are preserved: hardcoded ignored classes are merged
  with your list, and every layout is enabled by default.

## Notes

- Overcapacity windows are minimized by default now. Switch "Overcapacity
  windows handling" to Float to restore the previous behaviour.
- The pointer-follow options are off by default.
- Master builds keep the `-git` suffix; release builds have none.
