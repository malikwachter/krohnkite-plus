[Deskription]
This tool was written to automatically install/update krohnkite*.kwinscript files in a specified folder. This is only useful for developers.
I use it on my Arch Linux virtual mashine. I drag and drop a build into virtual mashine, and it installs automatically.

After a successful installation the daemon runs reload-script.py, so a running
Krohnkite switches to the new build without a logout. The reload is skipped when
Krohnkite is not loaded (fresh install or disabled plugin): the installed files
are used on the next login. Set reload_after_install = False in config.py to
install only.

[Requirenments]
notyfy-send - if you want notifications will showing up
reload-script.py - required. install.py looks for it in the autoinstall directory
first, then in the parent directory, and refuses to install when it is missing.
Pass --reload-script PATH to use another location; that path is written to
config.py.
qdbus6 and a running KWin session - to apply a build without logging out.

[Installation]
chmod +x install.py
./install ~/folder_when_krohnkite_scripts_will_appear

The default search finds ../reload-script.py in a repository checkout. For a
standalone copy, put reload-script.py next to autoinstalld.py or pass
--reload-script.

1. Creating .venv.
2. Update pip
3. Install watchdog
4. Generate config.py
5. Generate systemd krohnkite_autoinstall.service
6. move service to ~/.config/systemd/user
7. Run and enable the service
